# 202-introduction-to-the-project.md



This is going to be an ETL project.

We will use
«Lakeflow Declarative Pipelines» (aka «Delta Live Tables»)
to build a streaming pipeline.

It will consist of:

- streaming tables

- «materialized views»

- stream-to-static `JOIN`s

- stream-to-stream `JOIN`s

- window aggregations and «watermarking»
