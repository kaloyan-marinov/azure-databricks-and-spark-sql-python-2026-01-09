# 151-databricks-git-folders.md

source:
https://learn.microsoft.com/en-us/azure/databricks/repos/

> <u>Azure Databricks Git folders</u>
> is
> a visual Git client and API
> that integrates Git repositories within your [Azure Databricks] workspace
> [and supports common Git operations
> (such as cloning a repo, committing and pushing, branch management, and the like)].



So:

- your Databricks Workspace is basically your development environment,

- and the GitHub repository is the remote repository.



In summary,
the point of creating a `Git Folder` in a Databricks Workspace
is
to be able to leverage version control
when developing files and notebooks directly in that Databricks Workspace.
(This is one way for teams to collaborate with one another in the Databricks environment.)
