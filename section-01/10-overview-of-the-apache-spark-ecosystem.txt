There are 3 core data structures in Spark for distributed processing:


            RDDs                    Spark DataFrames            Datasets

API Level   low level, functional   high level, declarative     mainly used in Scala and Java workloads,
                                                                and not in Python



Today, DataFrames are the standard for most data-processing tasks in Spark
and
that's what we'll be focusing on in this course.
(RDDs will be outside the scope of this course.)
